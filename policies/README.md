# Security Policies

## Purpose

This directory is reserved for security policy definitions and IAM permission configurations. It currently contains this planning document; policy files have not yet been implemented.

## Planned Components

- IAM execution role policies
- Least-privilege permission definitions
- Approved remediation rules
- Resource-specific security policies

## Security Principles

- Grant only the permissions required.
- Avoid wildcard permissions wherever practical.
- Separate detection permissions from remediation permissions.
- Restrict remediation to approved resources.
- Review policy changes before deployment.

## Development Status

Planned — policies have not yet been implemented or validated.
